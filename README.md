# Sublime Friends — catálogo de bordados e personalizados

Site mobile-first da Sublime Friends. A vitrine prioriza patches bordados personalizados, uniformes e camisas, jalecos e bonés. Presentes personalizados ficam como linha complementar.

## Publicação atual

- Pedidos: WhatsApp +55 71 99317-5215
- Publicação: GitHub Pages, atualizada automaticamente após commits na branch `main`.
- Envio: etiquetas pelo Melhor Envio; para localidades mais distantes, atendimento pode encaminhar link de compra pela Shopee ou Mercado Livre.

## Categorias

- `patches.html`: patches, incluindo fotos reais de exemplos enviados pela proprietária.
- `uniformes.html`: uniformes e camisas bordadas.
- `jalecos.html`: jalecos personalizados.
- `bones.html`: bonés bordados.
- `presentes.html`: canecas, azulejos e camisetas estampadas.

Cada página tem chamada para orçamento no WhatsApp. O site é um catálogo com atendimento, sem carrinho, pagamento ou preço automático.

## Arquivos principais

- `index.html`: início, navegação, categorias, galeria, informações de envio e dúvidas frequentes.
- `styles.css`: identidade visual e layouts responsivos.
- `nav.js`: menu recolhível para celular.
- `sitemap.xml` e `robots.txt`: arquivos básicos de descoberta por buscadores.
- Imagens `.jpeg` dos patches: fotos reais dos exemplos enviados pela proprietária.
- Imagens `.png` das demais vitrines: imagens ilustrativas geradas para a composição inicial. Troque por fotos próprias assim que puder.

## O que completar na próxima rodada

1. Acrescentar os links reais da Shopee e do Mercado Livre, se quiser atalhos diretos.
2. Substituir as imagens ilustrativas de uniformes, jalecos, bonés e presentes por fotos dos produtos reais.
3. Informar a cidade/região atendida, opções de peça, quantidade mínima, prazo típico e condições de frete para enriquecer as páginas com informações exatas.
4. Depois de escolher um domínio próprio, configurá-lo em Settings → Pages e cadastrar o site no Google Search Console.

As páginas já incluem títulos, descrições e termos de busca relacionados aos produtos, escritos de forma natural. SEO ajuda a indexação, mas não garante posição ou prazo para aparecer nos resultados.
